This project explores how Singular Value Decomposition (SVD) can be used to represent and compress images. Although modern image compression such as jpeg rely on the Discrete Cosine Transform (DCT), as calculating SVD’s becomes computationally expensive for large datastructures, SVD’s remains as a good foundational concept for understanding image processing. Therefore, this presentation will give a introduction to the mathematics of image representation.

How an SVD works

Belwo is a simple example of how an SVD of the matrix A would look like A = \begin{bmatrix} 1 & 0 \\ 0 & 2 \\ 0 & 0 \end{bmatrix} \in \mathbb{R}^{3 \times 2}

The Singular Value Decomposition (SVD) of A is given by

A = U \Sigma V^T

where

U\Sigma V^T = \begin{bmatrix} 0 & 1 & 0 \\ 1 & 0 & 0 \\ 0 & 0 & 1 \end{bmatrix} \begin{bmatrix} 2 & 0 \\ 0 & 1 \\ 0 & 0 \end{bmatrix} \begin{bmatrix} 0 & 1 \\ 1 & 0 \end{bmatrix} \tag{1}

The dimensions of the matrices are therefore

\underbrace{(3 \times 3)}_{U} \underbrace{(3 \times 2)}_{\Sigma} \underbrace{(2 \times 2)}_{V^T} = (3 \times 2).

Thus, the SVD decomposes the original 3 \times 2 matrix into three matrices whose dimensions allow them to be multiplied back together to reconstruct A.

The Low-Rank Approximation Problem

Now that we have seen the full SVD, we can explore what happens when we truncate it. This leads to a fundamental question known as the low-rank approximation problem: for a given rank k, how do we find a simpler matrix A_k that is as close as possible to our original matrix A? \ The Eckart–Young–Mirsky theorem provides the mathematical answer, the optimal rank-k approximation is obtained simply by keeping the k largest singular values and their corresponding singular vectors, while discarding the rest. ### Rank 1 example

Continuing from the SVD in Equation 1, if we set the rank to k = 1, we keep only the first column of U, the first singular value of \Sigma, and the first row of V^T giving us \begin{bmatrix} 0 \\ 1 \\ 0 \end{bmatrix} \begin{bmatrix} 2 \end{bmatrix} \begin{bmatrix} 0 & 1 \end{bmatrix}= 2* \begin{bmatrix} 0 \\ 1 \\ 0 \end{bmatrix} \begin{bmatrix} 0 & 1 \end{bmatrix}= \begin{bmatrix} 0 & 0 \\ 0 & 2 \\ 0 & 0 \end{bmatrix} This rank-1 matrix retains the same 3 \times 2 dimensions, but it only captures the most dominant feature (the largest value, 2) while omitting secondary details.

Rank 2 example

If we set k = 2, we include the second singular component giving us \begin{bmatrix} 0 & 1 \\ 1 & 0 \\ 0 & 0 \end{bmatrix} \begin{bmatrix} 2 & 0 \\ 0 & 1 \end{bmatrix} \begin{bmatrix} 0 & 1 \\ 1 & 0 \end{bmatrix} = \begin{bmatrix} 1 & 0 \\ 0 & 2 \\ 0 & 0 \end{bmatrix} Notice that the result is the exact original matrix A. Because A is a 3 \times 2 matrix, and as the maximum possible rank is 2. k = 2 represents a full-rank reconstruction, meaning 100% of the original information is recovered.
